## ✨ Mejoras y Ajustes en esta Edición (Juansher Edition)

Esta versión incorpora refinamientos específicos diseñados para la experiencia táctil en smartphones y tablets:

- **Panel de fuentes optimizado**: Carga inmediata de las fuentes obtenidas en la búsqueda inicial al abrir el panel en plena reproducción, con opción de actualización manual a demanda.
- **Resaltado de reproducción**: Identificación visual de la fuente activa mediante la etiqueta **`Reproduciendo`** y marco de acento en el reproductor.
- **Transparencia en el versionado**: Línea superior reservada para la versión oficial base del autor original y línea inferior dedicada al versionado interno de esta edición personalizada.
- **Sincronización fluida**: Conservación íntegra de la sincronización de reproducción y biblioteca entre dispositivos.

## 📥 Descargas e Instalación

Puedes descargar los paquetes APK compilados directamente desde la sección de versiones:

👉 **[Ver Últimas Versiones y Descargas APK](https://github.com/AlessandroA586/NuvioMobile/releases/latest)**

- **`arm64-v8a`**: Recomendado para casi todos los teléfonos y tablets modernos de 64 bits.
- **`armeabi-v7a`**: Diseñado para dispositivos móviles de 32 bits o versiones anteriores de Android.
- **`universal`**: Instalador compatible con cualquier dispositivo Android.

---

## 🛠️ Compilación desde el código fuente

```bash
git clone https://github.com/AlessandroA586/NuvioMobile.git
cd NuvioMobile
./gradlew :androidApp:assembleFullRelease
```

*Construido con Kotlin Multiplatform y Compose Multiplatform.*
